The trick

ClickFix pages claim something has failed — a bot check, a document, a microphone, a browser update — then offer a "manual fix": press Win+R (or open Terminal), paste, press Enter. The page has already put an attacker's command in your clipboard.

It works because the web page cannot run code on your machine, so it persuades you to run it on its behalf. Nothing is downloaded, so nothing is scanned or blocked, and every permission prompt is satisfied because you gave the permission yourself.

In a real campaign, pressing Enter typically installs an infostealer that takes saved passwords and session cookies — and session cookies get past multi-factor authentication.

Keep doing this

  • No legitimate verification, update or repair ever asks you to paste a command into Run, PowerShell or Terminal.
  • If something puts text in your clipboard that you did not copy, close the page.
  • Report it — even when you did not fall for it. Early reports are how the rest of the organisation gets warned.

Worth knowing

If a colleague tells you they already pressed Enter on one of these: disconnect the device from the network, leave it powered on, and contact {{ cfg.operator }} straight away. Speed matters much more than embarrassment — sessions can be revoked before they are used.
